# Execution data

The two batch directories contain matched baseline and improved controller CSV. `demo10005_v001` contains the separate clean-restored demonstration CSV. `paired_results_data.json` records the derived comparison. Original Actor logs are downloadable from the Release; `raw_release_manifest.json` lists their sizes and SHA256 values.

Historical single-run and partial-run data are kept distinct from the completed twenty-part batches. These records describe the tested virtual cell, not hardware performance.
